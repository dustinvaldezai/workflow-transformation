# Workflow Overview

This project uses a staged research workflow designed to improve speed, consistency, and reviewability.

## Process

Source Intake  
↓  
Structured Extraction  
↓  
Thematic Classification  
↓  
Evidence Validation  
↓  
Synthesis  
↓  
Human Review  
↓  
Decision-Ready Output

## Design principle

Each stage has one clear job.

Separating the workflow into stages makes it easier to inspect intermediate outputs, identify errors, verify evidence, and preserve human judgment where interpretation matters.
